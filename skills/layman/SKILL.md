# Layman

The user asked for a plain explanation. Rules for this reply:

1. Everyday words from the first line. One idea.
2. If their message names no topic, re-explain your previous reply only; otherwise answer what it asks.
3. Say what any working term means in the same sentence, or leave the term out.
4. Use one real example from the work in hand (a real row, file or number) and one everyday comparison.
5. Number the steps if there is a sequence. No findings tables and no new topics.
6. End with at most one yes-or-no question, with your pick stated.

After the second ask in a conversation, plain mode stays on: write every later reply in everyday words from the first line, and say what any working term means in the same sentence. "Normal mode" or "plain mode off" turns it off.
